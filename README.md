# reels — norte.local

Reels diarios con voz para Instagram (@norte.local_), generados automáticamente.

- `PLAN_DIARIO.md` — lo que hace la tarea programada cada día.
- `historias/` — guion y datos de cada reel.
- `videos/` — los vídeos publicados (de aquí los lee Instagram).
- `generador/` — programa que crea el vídeo (voz Piper "davefx", animación y música propia).
- `datos/` — registro de reels y métricas, aprendizajes y rotación de horarios.
- `referencias/` — sube aquí reels de otros que quieras que analice.
